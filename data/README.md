# Data statement

The project references CIFAR-10 and other image examples used in the feature-extraction coursework. Raw image archives are excluded because they are external datasets and are not necessary to review the feature pipeline.

Download CIFAR-10 through Torchvision or its official source, keep the archive/cache outside the repository, and update notebook paths for any additional authorized image set. Expected inputs are RGB images and optional OCR-readable text regions.
