# Image Feature Extraction with ORB, HOG, and Bag-of-Visual-Words

**Timeline:** October 2025  
**Category:** Main project

This project compares handcrafted local and global image representations. It extracts HOG and ORB descriptors, builds a Bag-of-Visual-Words vocabulary with K-Means, and prepares features for downstream image analysis and classification.

## Stack

Python, OpenCV, scikit-image, NumPy, Pandas, scikit-learn, Torchvision, HOG, ORB, Bag-of-Visual-Words, K-Means, CIFAR-10, and Tesseract OCR.

## Repository contents

- `src/` — feature-extraction notebooks.
- `reports/` — project report.
- `data/README.md` — dataset provenance and excluded-data instructions.
